## 1. Описание проекта

В рамках работы реализован базовый генетический алгоритм (ГА) на языке Python для решения задачи глобальной непрерывной минимизации многомерной функции Гриванка.

### Архитектура и операторы:
* **Представление:** вещественное кодирование ($d=10$, генотип напрямую совпадает с фенотипом).
* **Селекция родителей:** турнирный отбор с размером турнира $k=3$.
* **Кроссинговер:** вещественный арифметический кроссинговер (линейная комбинация векторов родителей).
* **Мутация:** аддитивная гауссовская мутация параметров ($\sigma = 10.0$).
* **Обработка ограничений:** отсечение (clipping) вещественных координат по границам $[-600, 600]$.
* **Элитизм:** сохранение 1 лучшей особи каждого поколения без модификаций.
* **Критерий остановки:** фиксация числа поколений (150 поколений).
