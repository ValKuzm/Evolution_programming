## 1. Описание проекта

В рамках работы реализован базовый генетический алгоритм (ГА) на языке Python для решения задачи глобальной непрерывной минимизации многомерной функции Гриванка.

### Архитектура и операторы:
* **Представление:** вещественное кодирование ($d=10$, генотип напрямую совпадает с фенотипом).
* **Селекция родителей:** турнирный отбор с размером турнира $k=3$.
* **Кроссинговер:** вещественный арифметический кроссинговер (линейная комбинация векторов родителей).
* **Мутация:** аддитивная гауссовская мутация параметров ($\sigma = 10.0$).
* **Обработка ограничений:** отсечение (clipping) вещественных координат по границам $[-600, 600]$.
* **Элитизм:** сохранение 1 лучшей особи каждого поколения без модификаций.
* **Критерий остановки:** фиксация числа поколений (150 поколений).

# Лабораторная работа № 2. Генетический алгоритм для дискретной задачи с ограничениями

## 1. Описание проекта

В рамках работы реализован дискретный генетический алгоритм (ГА) на языке Python для решения задачи комбинаторной оптимизации (многомерный рюкзак с конфликтами) — формирования комплекта оборудования для лаборатории максимальной суммарной полезности.

### Архитектура и операторы:
* **Представление особи:** бинарная строка фиксированной длины $N = 35$ ($x_i \in \{0, 1\}$, где $1$ — включение прибора в комплект).
* **Селекция родителей:** турнирный отбор с размером турнира $k = 3$.
* **Кроссинговер (сравниваемые операторы):**
  * двухточечный кроссинговер (`two_point`, $p_c = 0.8$);
  * равномерный кроссинговер (`uniform`, $p_c = 0.8$).
* **Мутация:** побитовая инверсия (`bit-flip`) с вероятностью $p_m = 1/N \approx 0.0286$.
* **Обработка ограничений (сравниваемые подходы):**
  * *Метод жадного ремонта (`repair`):* принудительное исключение конфликтующих пар (удаляется менее полезный прибор) и приборов с наименьшей удельной полезностью $u_i / (c_i + 0.1 p_i)$ до соблюдения лимитов бюджета ($B_{\max} = 962$) и мощности ($P_{\max} = 4696$).
  * *Метод штрафных функций (`penalty`):* снижение фитнеса пропорционально величине нарушения ограничений ($\lambda = 50$).
* **Базовый метод для сравнения (Baseline):** конструктивная жадная эвристика, сортирующая оборудование по убыванию удельной полезности.
* **Элитизм:** сохранение 1 лучшей особи каждого поколения без модификаций.
* **Критерий остановки:** фиксация числа поколений ($120$ поколений).
